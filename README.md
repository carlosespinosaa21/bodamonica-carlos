# Invitación de Boda - Mónica & Carlos

## 📋 Descripción

Invitación digital para la boda de Mónica y Carlos, con un diseño elegante y funcionalidades interactivas para gestionar la asistencia de los invitados.

## 🏗️ Estructura del Proyecto

```
bodamonica-carlos/
├── index.html                 # Página principal
├── assets/                    # Recursos del proyecto
│   ├── css/

│   ├── js/
│   │   ├── countdown.js      # Contador regresivo
│   │   ├── music.js          # Control de música
│   │   ├── modals.js         # Modal de dress code
│   │   ├── form-handler.js   # Formulario de asistencia
```

## ✨ Características

- **Diseño responsive**: Se adapta a diferentes tamaños de pantalla
- **Contador regresivo**: Muestra el tiempo restante hasta la boda
- **Video de invitación**: Video promocional de la ceremonia
- **Formularios interactivos**: 
  - Confirmación de asistencia
  - Sugerencias musicales
- **Galería de dress code**: Ejemplos visuales del código de vestimenta
- **Música de fondo**: Control de reproducción de música ambiente
- **Integración con Google Sheets**: Los formularios se envían a una hoja de cálculo

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos y animaciones
- **JavaScript (Vanilla)**: Funcionalidades interactivas
- **Google Fonts**: Tipografías Great Vibes y Poppins
- **Font Awesome**: Iconografía
- **Google Apps Script**: Backend para formularios

## 🚀 Instalación y Uso

1. Clona el repositorio o descarga los archivos
2. Abre `index.html` en tu navegador web
3. El sitio funciona completamente sin necesidad de servidor web

## 📱 Funcionalidades Principales

### Contador Regresivo
- Cuenta automáticamente hasta la fecha de la boda
- Se actualiza cada segundo
- Muestra días, horas, minutos y segundos

### Formulario de Asistencia
- Permite confirmar asistencia a la boda
- Envía datos a Google Sheets para gestión
- Validación de campos requeridos

### Control de Música
- Botón flotante para controlar la música de fondo
- Play/Pause con indicadores visuales
- Música ambiente opcional para los visitantes

### Modales Informativos
- **Dress Code**: Galería con ejemplos de vestimenta
- **Tips y Notas**: Información importante para los invitados
- **Sugerencias Musicales**: Formulario para sugerir canciones
